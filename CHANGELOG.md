# История изменений

## 0.2.0 — Pawlish

Первый публичный кандидат на релиз, развитие Mani Webs.

- Новое название, оранжевая тема, собственная иконка, русскоязычный README и `docs/`.
- Webhook fail-closed, только предварительно настроенный личный чат; исправлен путь в документации.
- Отзыв прежнего небезопасного поведения сидера, защита `.env` в Docker.
- Напоминания отмечаются отправленными только после успешного ответа Telegram; повторная проверка актуальности записи, ограниченные повторы и уникальная очередь.
- SQLite-триггеры для пересечений, статистики визитов, защиты истории услуги.
- Финансовые отчёты включают обе граничные даты, защита CSV, поддержка ранее допустимой оплаты картой, ограничение периода экспорта.
- Ежемесячные расходы идентифицируются шаблоном и месяцем; исключено автоматическое дублирование первого месяца.
- Корректная настройка локального Docker-запуска, отдельные worker/scheduler, согласованные статические ресурсы, проверка Laravel `/up`.
- Регрессионные тесты, CI и аудит lock-файлов. Mozilla Public License 2.0 (MPL-2.0); Pawlish — самостоятельный авторский проект Alexander Motorin (Crimson).
