# Trust, but verify the paws

Тесты не используют настоящий Telegram, реальные данные клиентов и production-базу. PHPUnit работает с SQLite `:memory:`. В `src/` выполните:

```bash
composer install
npm ci
npm run build
php artisan test
composer audit --locked --no-dev
npm audit --audit-level=high
```

CI `Check Pawlish` выполняет три задания: PHP-тесты и сборка Vite, сборка Docker + HTTP smoke test, аудит зависимостей. Проверки охватывают авторизацию экспорта, CSV-ячейки, Telegram webhook и доставку, статистику визитов, пересечения и отменённые записи, удаление услуг с историей, календарные границы расходов и повторяющиеся платежи.

Миграции используют реальные SQLite-триггеры и уникальный индекс, а не только проверки PHP. Для ручной приёмки поднимите отдельный стек с фиктивными клиентами, проверьте календарь на телефоне и компьютере, измените оплату и цену, попробуйте пересекающуюся запись, скачайте CSV/PDF. Проверьте русский интерфейс и отсутствие внешнего доступа к 9000. Не включайте рабочий Telegram-токен в CI.

При подготовке архива выполнен синтаксический анализ PHP и автономные проверки SQL/CSV; полноценный Laravel, frontend и контейнерный CI должен пройти после публикации. Не выпускайте тег до успешного CI и проверки UI.
